# 每日任务与周节奏

> 这套节奏已经内置成「任务模板」。打开「今日任务」→ 点「生成计划」，系统会按当天是星期几自动排好；你不用每天想"今天该干什么"。

---

## 一、设计原则

1. **英语每天 ≥ 2 小时，拆成 4 段**。连续 2 小时学英语对口语和听力都不划算，拆开反而记得住。
2. **每天只有 1 个 P0（必须推进）**。P0 不是"最重要"，是"今天不做，今天就白过了"。
3. **单块任务 ≤ 90 分钟**。超过 90 分钟的任务要拆，否则一定会拖。
4. **没完成不补，顺延**。补昨天的任务会让你每天欠债，两天后就放弃。系统里点「移到明天」即可。
5. **每周留半天空白**。不是偷懒，是给突发事情和恢复留余量。
6. **不把"今天完成多少"当作自我价值评分**。看的是 4 周趋势，不是单日。

## 二、工作日节奏（周一至周五）

| 时间 | 时长 | 任务 | 说明 |
| --- | --- | --- | --- |
| 07:00–07:30 | 30′ | **精听**（六级听力 / 商务对话） | 盲听 → 听写关键词 → 对照原文标音变。只做 1 段，做透。 |
| 12:30–12:55 | 25′ | **词块**（外贸高频 + 六级） | 记词块不记单词：place an order / lead time / MOQ。 |
| 19:00–19:45 | 45′ | **外贸知识 1 条**（P0） | 精读知识库一条，回答："这条在哪个环节会改变我的决策？" |
| 20:00–20:40 | 40′ | **商务邮件 1 篇**（训练室） | 先写，再看要点；写完提交自检。 |
| 21:00–21:20 | 20′ | **跟读 / 影子练习** | 用报价或产品介绍话术，录音回放。 |
| 21:20–21:30 | 10′ | **今日复盘** | 三问：推进了什么 / 卡在哪 / 明天最重要的一件事。 |

**英语合计：30 + 25 + 40 + 20 = 115 分钟**，加上复盘里的英语内容，稳定超过 2 小时。
**外贸：45 分钟**（周末补整块）。

> 如果某天课多，只保 **P0（外贸知识）+ 精听 30′ + 复盘 10′**，其余顺延。宁可少，不要断。

## 三、周末节奏

### 周六：整块实战 + 真题
| 时间 | 时长 | 任务 |
| --- | --- | --- |
| 上午 | 130′ | **六级真题 1 套（限时）**，对答案后按错因分类（词汇 / 定位 / 推理 / 时间） |
| 下午 | 90′ | **整块实战**：算一次 FOB→CIF 报价，或写一整套「询盘 + 报价 + 跟进」 |
| 晚上 | 20′ | 跟读 + 复盘 |

### 周日：复盘 + 计划
| 时间 | 时长 | 任务 |
| --- | --- | --- |
| 上午 | 45′ | **周复盘**（复盘十问）+ 回看本周错误本，找出重复出现的问题 |
| 下午 | 30′ | **知识抽查（闭卷）**：随机 3 条，用自己的话解释并举例 |
| 晚上 | 20′ | **下周计划**：定 3 个关键结果，把整块任务排到具体哪天 |

## 四、CET-6 冲刺（2026-10-20 → 2026-12-19）

目标：**500+**，听力与阅读拉分；同时把六级词汇迁移到商务场景。

| 阶段 | 时间 | 重点 | 每周硬指标 |
| --- | --- | --- | --- |
| 第 1–4 周 | 10/20–11/15 | 听力精听 + 高频词块 + 阅读长难句 | 真题 1 套/周；精听 5 次/周；词块 100 个/周 |
| 第 5–7 周 | 11/16–12/06 | 真题 2 套/周 + 写作模板 + 翻译 | 真题 2 套/周；作文 2 篇/周；翻译 3 段/周 |
| 第 8 周 | 12/07–12/13 | 全真模拟 + 错题回炉 | 模拟 2 套；错题重做 |
| 第 9 周 | 12/14–12/19 | 只复习错题与高频词，不再做新题 | 每天 60′ 错题 + 30′ 听力保持 |

> 六级只是**门槛**。真正决定 2028 求职的是「能不能写出一封让客户回复的开发信」。所以六级冲刺期间，商务邮件练习不要停，可以减到每周 2 篇。

## 六、每周与每月节奏

**每周（周日）**
- 周复盘：本周 3 个关键结果完成情况 → 1 条改进规则
- 检查：有没有 3 天以上断档？断在哪一天？为什么？
- 排下周：先把整块任务（真题、模拟订单）占住时间，再填日常任务

**每月（最后一个周日）**
- 项目复盘：本月做的项目（真实/模拟）各写 1 篇
- 知识库体检：把"待核实"条目重新查一遍官方来源，更新核实日期
- 数据备份：设置页 → 导出全部数据，存网盘
- 目标校准：里程碑是否还合理？要不要删掉一个不重要的目标？

**每季度**
- 简历更新：只写能拿出证据的事（邮件、报价单、复盘报告、真实项目数据）
- 能力差距复核：对照目标岗位 JD，看还差哪 3 项

## 七、任务量控制（很重要）

| 情况 | 做法 |
| --- | --- |
| 今天只有 1 小时 | 只做 P0 + 精听 30′ + 复盘 10′ |
| 连续 3 天没完成 | 把每日任务砍掉 1/3，先恢复节奏，不要加码 |
| 某任务连续 3 次被顺延 | 要么拆小，要么删掉——它对你可能不重要 |
| 状态好、想多做 | 做"整块实战"，不要加日常任务数量 |
| 考前一周 | 只保留真题 + 错题，停掉知识库新条目 |

---

## 八、每天在系统里的动作（3 分钟）

1. 早上打开驾驶舱，点「生成今日计划」。
2. 白天完成一项就勾一项（勾选会自动累计学习分钟）。
3. 晚上写「今日复盘」10 分钟，并在驾驶舱补记任务外的学习时间。

> 一周后你会看到一条曲线。它不评价你，只是告诉你：这周到底投入了多少。
