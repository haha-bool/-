# 使用说明

## 一、启动与关闭

- **启动**：双击 `启动工作台.cmd`。会自动打开浏览器（`http://127.0.0.1:7788`）。
- **关闭**：在黑色窗口按 `Ctrl + C`，或直接关闭窗口。关闭时会自动存一份快照。
- 如果 7788 被占用，系统会自动换到 7789、7790……终端里会打印实际地址。
- 想固定用某个端口：在终端里执行 `set PORT=8000 && node server.mjs`。

> 不需要联网，也不需要 `npm install`。只需要电脑上装了 **Node.js 22+**（`node -v` 可查）。

---

## 二、每天怎么用（3 分钟成本）

1. 早上打开 **驾驶舱**，点右上角「生成今日计划」。
2. 按 P0 → P1 → P2 的顺序做。完成一项点左边的方框，会自动累计学习分钟。
3. 晚上点「写一次复盘」，10 分钟填完。
4. 如果还有任务外学习（比如课上听英语），在驾驶舱「今日记录」里补记分钟。

**不要每天新增任务**。系统给的 6 项就是一天的量；想加，先删一项。

## 三、知识库怎么用才有效

1. **先读「通俗解释」**，能用自己的话讲一遍，再去读「专业解释」。
2. 读「在真实业务里怎么用」时，问自己：**这条会改变我在哪个环节的哪个决定？**
3. 把答案写进「我的笔记」，比抄定义有用 10 倍。
4. 掌握度老实填：
   - 1 知道 = 听说过
   - 2 能解释 = 能讲清概念
   - 3 能应用 = 能在真实订单里用（比如能算出 FOB 报价）
   - 4 能教人 = 能讲给别人听且经得起追问
5. 看到 **「动态信息 · 必须核实」** 标记的条目（关税、平台费率），用之前一定重新查官方来源，点「标记已核实」更新日期。过期的条目会出现在驾驶舱的「待核实 / 风险」里。

## 四、英语训练室怎么用

1. 选一个场景 → 读「业务背景」与「任务」。
2. **先自己写完**。写不出来就先列提纲，再一句句展开。不要先看要点。
3. 点「保存并自检」，看四块内容：
   - **本地检查**：篇幅、称呼、结尾、主题、句长、模板化表达——只是最低限度检查，**不是评分**。
   - **自检对照**：5 个维度自己勾。
   - **结构对照**：骨架，不是范文。
   - **这类写作最常见的错误**：对照自己有没有踩。
4. 点「复制」把 **AI 反馈包** 粘到任意 AI 对话里（DeepSeek / ChatGPT 都行），让它逐句改。
5. 把改出来的东西存进「错误本」和「可复用表达」。
6. 同一个场景可以练多次——每次都是新记录，方便对比进步。

> 为什么不让系统直接改？因为"看别人改"和"自己写出来"是两种能力。求职面试时，没人替你写邮件。

## 五、复盘怎么写

数据库里已经有「劳务项目复盘」的空白位。第一次建议就写它，按这个顺序：

1. **事实**：时间线、当时你掌握的信息、关键决策点（不要写感受）。
2. **结果**：损失金额、影响人数、实际交付情况。
3. **责任划分**：哪些是你的决策责任（没现场核实），哪些是合作方未披露，哪些是外部条件。
4. **规则**：写成一句下次能直接执行的话，例如
   > "涉及他人吃住行的项目，签约前必须本人或委托可信第三方到现场拍视频确认，并把住宿标准写进书面协议。"

最后一步最重要：**把这句规则抄进知识库对应条目的「操作检查清单」**。

## 六、数据备份（请务必做）

| 方式 | 位置 | 说明 |
| --- | --- | --- |
| 自动快照 | `data/backups/backup-*.json` | 每次启动、关闭各一份，保留最近 30 份 |
| 手动导出 | 设置页 →「导出全部数据」 | 下载完整 JSON，建议每周日存网盘 |
| 立即快照 | 设置页 →「立即快照」 | 做重要修改前点一下 |

**恢复**：设置页 →「导入备份」→ 选择 JSON。导入会**覆盖当前全部数据**，导入前先导出一次。

**换电脑**：把整个 `personal-trade-os` 文件夹拷过去，双击启动即可（需要装 Node）。

## 七、常见问题

**Q：浏览器打开是空白/一直在转圈？**
A：看黑色窗口有没有报错。多半是 Node 版本太低（`node -v` 低于 22.5）。升级 Node 后重开。

**Q：端口被占用？**
A：系统会自动换端口，看终端打印的地址。或者关掉占用 7788 的程序。

**Q：数据存在哪？会上传吗？**
A：`data/trade-os.db`（SQLite 单文件）。不联网、不上传。可以把 `data` 文件夹整个拷走。

**Q：能在这个系统里用 AI 自动批改英语吗？**
A：第一阶段不能（不内置 API Key）。现在的方式是复制「AI 反馈包」到你的 AI 对话里，把结果手动记回错误本。第二阶段可以加入"自备 API Key"的自动批改。

**Q：为什么没有客户管理和报价计算器？**
A：那是第二阶段。现在导航里不显示，就是还没做——不是隐藏功能，也不会给你假按钮。

**Q：任务完不成怎么办？**
A：点开任务 →「移到明天」，不要补昨天的。连续 3 天完不成，就把每日任务砍掉 1/3，先恢复节奏。

**Q：目标进度为什么一直是 0%？**
A：进度 = 已完成里程碑 / 全部里程碑。去「目标与项目」勾选已完成的里程碑，进度才会动。这是故意的：不让你用手填数字安慰自己。
